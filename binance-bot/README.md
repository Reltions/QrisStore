# بوت تداول Binance يتحكم فيه من ديسكورد

بوت مكتوب بـ Node.js يتداول على Binance (Spot) وتتحكم فيه بأوامر Slash في ديسكورد.
**يشتغل على Testnet (فلوس وهمية) كإعداد افتراضي.**

> ⚠️ البوت ما يضمن ربح. هو ينفذ الاستراتيجية بس، وممكن يخسر. جربه على Testnet أسابيع قبل أي فلوس حقيقية.

## وش يسوي
- **الاستراتيجية:** يشتري إذا المتوسط المتحرك السريع (EMA 9) قطع البطيء (EMA 21) لفوق و RSI تحت 70،
  ويبيع إذا صار تقاطع لتحت. الإشارات تُحسب على الشموع المقفلة بس.
- **إدارة المخاطر:**
  - مبلغ ثابت لكل صفقة
  - وقف خسارة وجني ربح بالنسبة المئوية
  - حد خسارة يومي: إذا وصله يوقف فتح صفقات لين بكرة
  - صفقة وحدة مفتوحة بالمرة
- **ديسكورد:** أوامر تشتغل لك إنت بس (`OWNER_ID`)، وتنبيه في قناة خاصة مع كل صفقة.
- **Backtest:** يختبر الاستراتيجية على أسعار Binance الحقيقية القديمة.
- يحفظ حالته في `data/state.json`، فلو طفّيته وشغلته يكمل على نفس الصفقة.

## التشغيل

### 1. التثبيت
تحتاج Node.js 18 أو أحدث.
```bash
cd binance-bot
npm install
cp .env.example .env
```

### 2. مفاتيح Binance Testnet
1. ادخل https://testnet.binance.vision وسجّل دخول بحساب GitHub
2. اضغط **Generate HMAC_SHA256 Key**
3. حط المفتاحين في `.env`:
   ```
   BINANCE_API_KEY=...
   BINANCE_API_SECRET=...
   ```
الحساب التجريبي يجيك فيه رصيد وهمي جاهز.

### 3. بوت ديسكورد
1. من https://discord.com/developers/applications سوّ Application جديد، ومن قسم **Bot** انسخ التوكن وحطه في `DISCORD_TOKEN`
2. من **OAuth2 → URL Generator** اختر `bot` و `applications.commands`، وصلاحية `Send Messages`، وضيف البوت لسيرفرك الخاص
3. فعّل Developer Mode في ديسكورد (الإعدادات ← متقدم)، وبعدها كليك يمين وانسخ:
   - ID السيرفر في `GUILD_ID`
   - ID حسابك في `OWNER_ID`
   - ID القناة اللي تبي التنبيهات فيها في `NOTIFY_CHANNEL_ID`

> لو تركت `DISCORD_TOKEN` فاضي، البوت يشتغل بدون ديسكورد ويطبع كل شي في الـ terminal.

### 4. اختبر الاستراتيجية أول
```bash
npm run backtest -- --days 90
```
يطلع لك: عدد الصفقات، ونسبة الفوز، ومتوسط الربح والخسارة، وأكبر نزول، ومقارنة مع "لو اشتريت وخليتها".
جرب تغير الإعدادات في `.env` (`TIMEFRAME`، `EMA_FAST`، `STOP_LOSS_PCT` ...) وشوف وش يتغير.

### 5. شغّل البوت
```bash
npm start
```
بعدها في ديسكورد اكتب `/start`.

## الأوامر

| الأمر | وش يسوي |
|------|---------|
| `/status` | الوضع، آخر إشارة، الصفقة المفتوحة، ربح اليوم |
| `/price` | السعر الحالي |
| `/balance` | رصيدك |
| `/start` | يشغّل التداول التلقائي |
| `/stop` | يوقف فتح صفقات جديدة (وقف الخسارة وجني الربح يظلون شغالين على الصفقة المفتوحة) |
| `/close` | يبيع الصفقة المفتوحة الحين |
| `/trades` | آخر 10 صفقات |

## الانتقال للتداول الحقيقي
لا تسويها إلا بعد ما تجرب على Testnet فترة كافية وتكون راضي عن النتائج.

1. سوّ مفتاح API من حسابك الحقيقي في Binance:
   - فعّل **Enable Spot & Margin Trading** بس
   - **لا تفعّل Enable Withdrawals أبدًا**
   - قيّد المفتاح على IP جهازك أو السيرفر
2. في `.env`:
   ```
   TESTNET=false
   CONFIRM_LIVE=YES
   ```
3. احذف `data/state.json` عشان يبدأ من جديد
4. ابدأ بمبلغ صغير تتحمل تخسره

## الأمان
- ملف `.env` موجود في `.gitignore`، **لا ترفعه على GitHub**
- الأوامر ترفض أي أحد غير `OWNER_ID`
- استخدم سيرفر ديسكورد خاص للبوت
- لو انسرق التوكن أو المفاتيح، احذفها فورًا من Binance ومن Discord Developer Portal

## ملاحظات
- الربح والخسارة المعروضين تقريبيين، والعمولة ممكن تنخصم بعملة ثانية (مثل BNB).
- الحد الأدنى للصفقة في Binance حوالي 5 دولار، فلا تحط `TRADE_AMOUNT_USDT` أقل من كذا.
- لازم البوت يكون شغال عشان وقف الخسارة يشتغل. لو طفّيت الجهاز، الصفقة المفتوحة تظل بدون حماية.
  للتشغيل 24 ساعة استخدم VPS أو `pm2`.
